# Guide de Contribution

Merci de votre intérêt pour contribuer à Clean Mail Subscriptions !

## 🎯 Comment Contribuer

### Signaler un Bug
1. Vérifiez que le bug n'a pas déjà été signalé dans les issues
2. Créez une nouvelle issue avec :
   - Description claire du problème
   - Étapes pour reproduire
   - Comportement attendu vs comportement actuel
   - Version du navigateur et de l'extension

### Proposer une Fonctionnalité
1. Vérifiez que la fonctionnalité n'a pas déjà été proposée
2. Créez une issue avec :
   - Description de la fonctionnalité
   - Cas d'usage
   - Avantages pour les utilisateurs

### Soumettre du Code
1. Forkez le projet
2. Créez une branche pour votre fonctionnalité (`git checkout -b feature/ma-fonctionnalite`)
3. Committez vos changements (`git commit -m 'Ajout de ma fonctionnalité'`)
4. Push vers la branche (`git push origin feature/ma-fonctionnalite`)
5. Ouvrez une Pull Request

## 📋 Standards de Code

### JavaScript
- Utilisez des noms de variables descriptifs
- Commentez le code complexe
- Suivez les conventions ES6+
- Évitez les fonctions trop longues

### CSS
- Utilisez des noms de classes descriptifs
- Organisez le CSS par sections
- Utilisez des variables CSS pour les couleurs récurrentes

### HTML
- Utilisez une structure sémantique
- Ajoutez des attributs `aria-` pour l'accessibilité
- Validez le HTML

## 🧪 Tests

Avant de soumettre :
- Testez sur Chrome/Edge
- Testez sur Firefox
- Vérifiez qu'il n'y a pas d'erreurs dans la console
- Testez les fonctionnalités principales

## 📝 Documentation

- Mettez à jour le README si nécessaire
- Ajoutez des commentaires pour le code complexe
- Documentez les nouvelles fonctionnalités

## 🔒 Confidentialité

- Respectez la confidentialité des utilisateurs
- Ne collectez pas de données personnelles
- Toutes les données doivent rester locales

## ❓ Questions

N'hésitez pas à ouvrir une issue pour poser des questions !
