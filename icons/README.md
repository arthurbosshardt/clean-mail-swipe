# Icônes de l'extension

Placez ici les icônes de l'extension aux tailles suivantes :
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

Vous pouvez créer ces icônes avec un outil comme :
- [Figma](https://www.figma.com/)
- [Canva](https://www.canva.com/)
- [GIMP](https://www.gimp.org/)
- [ImageMagick](https://imagemagick.org/)

Ou utiliser un générateur d'icônes en ligne.

Pour l'instant, l'extension fonctionnera sans icônes, mais elles sont recommandées pour une meilleure expérience utilisateur.
